# 桌面联系区自适应居中

## 目标

在大屏桌面端滚动到页面底部时，让联系区文字、按钮和电话在可见区域内更接近垂直居中，同时保持蓝色光晕贴住页面底边。

## 设计

- 仅在宽度大于 900px 的桌面端生效。
- 联系区最小高度设为视口高度减去约 96px 页脚高度。
- 使用现有纵向 Flex 布局的 `justify-content:center` 居中主体。
- 上下内边距改为视口相关的克制范围，内容较高时仍允许区块自然增高。
- 蓝色光晕伪元素、页脚、粒子和移动端布局保持不变。

## 验收

- 900px 高度的大屏中，联系区与页脚合计接近一屏，主体不再明显偏上。
- 内容高度超过可用空间时不裁切、不重叠。
- 手机端原有间距不变化。
- 本地直开、星点和底部粒子行为不回退。
