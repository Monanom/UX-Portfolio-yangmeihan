# 精选项目图片

本目录保留三组 JPG 原图。网页展示同名的 WebP 图片，顺序仍为封面、01、02……；原图不会被删除。

| 文件夹 | 项目 | 详情页顺序 |
| --- | --- | --- |
| `lecai-ai/` | 乐采百应 | 封面 + 01–12 |
| `ai-agent/` | 政企商品牌矩阵与视觉策略 | 封面 + 01–13 |
| `caiyun/` | 采云学院 | 封面 + 01–12 |

修改已有图片时，用同名 JPG 文件替换对应原图，再依次运行 `node generate-project-previews.mjs` 和 `python3 generate-optimized-images.py`，更新横向小图与 WebP。转换脚本需要 Pillow；未安装时可交给 Codex 运行。项目详情使用同尺寸、高质量的 WebP，JPG 原图始终保留在本地。新增、删除或调整页序时，还需要同步更新 `index.html` 中的项目图片清单及尺寸。桌面上的原始图片未移动，也未复制总封面、目录、封底和“其他”目录。
